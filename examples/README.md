# Candis examples

[Example catalog](../docs/en/examples.md) · [简体中文](../docs/zh/examples.md)

Each example is a standalone ESP-IDF application. From the repository root, use the ESP32-S31 toolchain to build it.

```sh
idf.py --preview -C examples/display build
```

See [USB and flashing](../docs/en/usb.md) to install an example. Check the catalog for each example's board and power requirements.
