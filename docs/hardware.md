# Candis 硬件与实测

兼容硬件修订 1.2，AM214Q480480LK2 模组，480×480 RGB565。

| 资源 | Candis 配置 |
| --- | --- |
| 主 I²C | I2C0，GPIO6 SCL、GPIO7 SDA，板外部上拉 |
| QSPI | SPI2，CLK GPIO12、CS GPIO10、D0～D3 GPIO11/13/14/9 |
| ST7801N | RESET GPIO2，TE GPIO8，MADCTL MY |
| CST9220 | 主 I²C，RESET GPIO3，INT GPIO1，触点坐标双轴镜像 |
| 屏电源 | TG28-ESP ALDO1，主 I²C 地址 0x34 |

- ST7801N V0.3 的 MSPI 时序表给出 20 ns 最小写周期。50 MHz 是默认配置。
  80 MHz 来自屏供应商示例及已有样机验证，用于台架对照，量产裕量仍需实测。
- 屏模组资料列出 VDDIO 上限 3.35 V。TG28-ESP 资料列出 ALDO1 典型条件下
  ±3% 公差，标称 3.3 V 的电压上端可到 3.399 V。硬件需确认实际电压、纹波、
  瞬态、模组批次规格和上电条件。BSP 默认只读取 ALDO1 状态。台架显式允许时
  才启用原先关闭的 ALDO1，结束时仅关闭由本实例开启的电源轨。
- ST7801N 使用 0x32 单线命令/地址、四线像素传输，CASET 与 RASET 要求
  偶数起点和范围。绘制时先合成完整 LVGL 脏区，再等 TE，按 MY 扫描方向从
  底部向上发 32 行 DMA 条带。每条带最长 30,720 字节。
- ST7801N 所需 QSPI 与面板命令直接用 ESP-IDF LCD panel I/O 实现。触摸用
  Espressif CST9220 组件，LVGL 任务与锁使用 ESP LVGL Port。

## 性能测量

在示例菜单启用自动采样，先测 256×192 持续动画 8 秒，再测 480×480 全屏动画
8 秒。日志分开记录成功提交帧率、TE Hz、每帧平均像素量、传输与等待时间、超时
和错误。采样期间保持屏幕无人触摸，以固定绘制窗口。

RX8130CE 接主 I²C，7 位地址 0x32。日历按 Epson RX8130CE 应用手册
第 13.2 节及第 14.1 节连续读取 0x10 起的寄存器，利用器件的进位冻结。
VLF 或 STOP 有效时返回错误。RTC 与 TG28 共用 GPIO0 中断，因此读取日历不写
标志或控制寄存器。

### RTC 深睡唤醒

综合测试板运行 RTC 示例时，先确认 `READ` 返回有效 UTC，再发送 `SLEEP`。示例保存
并屏蔽 TG28 中断，确认 GPIO0 处于高电平后启用 RX8130CE 每秒更新中断。重启后
回读 TG28 中断掩码和电源使能位。通过判据为深睡复位、GPIO0 EXT1 生效、5 秒兜底
定时器未触发、RTC 的 UF 有效以及恢复返回 `ESP_OK`。

2026-11-19 用同一镜像完成 3 轮台架验证。每轮以匹配的 ELF 经 JTAG 读取 `s_wake`，
五项判据均满足，保留的恢复记录 `s_saved` 已清零。每轮睡前 TG28 中断掩码为
`ff/fc/5f`，电源使能位为 `09/01/00`，唤醒恢复时均通过回读校验。
三轮 USB Serial/JTAG 均重新枚举，CDC 查询均超时。可在 OpenOCD 中加载本次镜像的
ELF 符号，暂停两核读取 `s_wake` 和 `s_saved`，读完恢复运行。走时精度、
后备供电保持和实际深睡电流仍需独立测量。

## 2026-11-19 台架数据

ESP32-S31，80 MHz QSPI。测试启用 FreeRTOS 两个 LVGL 软件绘制单元，PSRAM
XIP 和 5 ms 重绘检查周期。每个模式运行约 8 秒。

| 负载 | 成功提交帧数 | UI FPS | TE Hz | 平均准备 | 平均 PSRAM→面板条带传输 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 256×192 局刷 | 480 | 59.93 | 59.93 | 4.16 ms | 3.23 ms |
| 480×480 全刷 | 240 | 29.96 | 59.92 | 14.32 ms | 13.36 ms |

两次采样均无 TE 超时、面板传输错误或触摸读取错误。示例还完成一次停止和重启。
吞吐量来自 BSP DMA 提交统计。撕裂、双指触点、光学响应时间、长稳及温度电压裕量需单独验收。
同一负载打开原生 LVGL PPA 的对照只得到约 29.96/14.98 FPS，台架配置保留软件绘制。

## 扩展与资源冲突

- BB 和 Gamepad 都经 CN1、CN2 与 Candis 对插。扩展识别按 Mosaico V1 线格式校验
  134 字节和三段 CRC，匹配身份后由应用选择组件。默认启动不探测或写入 EEPROM。
- GPIO58/59 是 UART0 的原生引脚。仅在应用明确释放 UART0 且移除回环夹具后调用
  `candis_baseboard_probe()`。探测要求 DC1SW 已上电。
- 4-bit SDMMC 使用 GPIO20–25。正式扩展板 CD 为 GPIO39，综合测试板 CD 为 GPIO35。
  20 MHz 下实测 30,436 MiB TF 卡 3 次成功挂载、只读列目录和卸载。正式扩展板仍待验证。
- Gamepad 数字输入示例要求 DC1SW 和 ALDO3 已稳定供电。GPIO38 由 SW5 和 BMI270 INT1
  共用，外部上拉来自 ALDO3。数字输入示例和 BMI270 轮询驱动均不驱动 GPIO38。软件拒绝在 ALDO3 已开且 DC1SW 关闭时接管 DC1SW，也拒绝在 ALDO3 尚开启时关闭由 BSP 开启的 DC1SW。各轨的异常顺序待实板评估。
- BMI270 地址为 0x68。Espressif BMI270 驱动 1.1.0 将该设备配置为 400 kHz I²C，
  其他设备保留各自的事务时钟。驱动启动后回读 INT1_IO_CTRL 确认输出关闭。400 kHz 结论
  覆盖综合测试板和本轮组合负载，I²C 波形裕量与正式扩展板待测。
- 摄像头装在综合测试板，使用 GPIO39/40 控制和 GPIO46–57 DVP。同名引脚在别的扩展板
  可用于卡检测与游戏输入。使用各自的板型配置，GPIO 与电源不可混用。

## 参考实现

- Espressif ESP-BSP 的 ESP32-S31-Korvo-1 公开实现提供按需初始化及 LVGL 接口参考。
- ESP Board Manager 用外围设备表组织资源。Candis 用 C API 表达实际的共享总线与生命周期。
- ESP-Mosaico 提供底板描述符线格式与模块边界参考。LILYGO Device Driver 提供各板独立
  驱动目录参考。Candis 代码使用 ESP-IDF 及 Registry 官方依赖与自己的板级适配。
