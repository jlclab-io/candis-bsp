# Changelog

All notable changes to this component are documented in this file. Versions follow [Semantic Versioning](https://semver.org/).

## 0.1.0 (Unreleased)

- Added configurable DVP capture and sensor profile APIs for 17 supported camera drivers.
- Added stream, frame-copy, control, mode, and format operations.
- Added ESP-IDF 6.1 and 6.2 compatibility without a dependency on the Candis BSP.
