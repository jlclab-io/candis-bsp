# Changelog

All notable changes to this component are documented in this file. Versions follow [Semantic Versioning](https://semver.org/).

## 0.1.0 (Unreleased)

- Added board support for Candis revision 1.2 on ESP32-S31.
- Added display, touch, audio, power, RTC, storage, IMU, USB, and baseboard APIs.
- Added ESP-IDF 6.1 and 6.2 compatibility and a dependency on `jlclab/tg28-esp`.
